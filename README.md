# Libdoc2TestBench

Libdoc2TestBench is a Robot Framework Libdoc extension that generates import formats compatible with [TestBench](https://www.testbench.com).
It can be used to generate TestBench keywords and datatypes from Robot Framework libraries.


## Documentation

The documentation is available in the [docs](./docs) folder of this repository.


## Requirements

- Python 3.9 or higher
- TestBench version >= 3
